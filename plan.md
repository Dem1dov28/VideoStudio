# План исправлений Cartoon Drama Mode

## Проблемы генерации видео (FastGen)

### 1. Озвучка на неправильном языке
**Проблема:** Некоторые сцены озвучиваются на английском при выборе русского.

**Причина:** FastGen не всегда следует инструкции VOICEOVER LANGUAGE в промпте.

**Решение:**
- Добавить более явные инструкции для языка
- Указать язык в начале промпта (более заметно)
- Добавить пример голоса: "Russian male/female narrator voice"
- Возможно: использовать системный промпт перед основным

**Файлы для изменения:**
- `modes/mode6/video_generator.py` - функция `_build_video_prompt()`

---

### 2. Персонажи озвучивают ДЕЙСТВИЯ вместо СВОИХ СЛОВ (КРИТИЧЕСКАЯ ОШИБКА)
**Проблема:** Голос говорит "Авокадо флиртует, кукуруза замечает это..." — это описание действий, а не речь персонажей.

**Как ДОЛЖНО быть:** Персонажи говорят СВОИМ голосом, своими словами:
- Авокадо: "Ты мне вообще не нравишься!"
- Кукуруза: "Я знал, что так и будет."

**Причина:** В промпте нет чёткого текста реплик для каждого персонажа. FastGen генерирует описание происходящего вместо диалога.

**Решение:**
- В `scenario_writer.py` добавить поле `dialogue` в каждую сцену — конкретные реплики персонажей
- В промпт передавать точный текст реплик: кто что говорит
- Убрать любое упоминание закадрового голоса / narrator
- В промпте: "Characters SPEAK their lines aloud. No narrator."

**Файлы для изменения:**
- `modes/mode6/scenario_writer.py` — добавить поле `dialogue: list[dict]` в `CartoonScene`
- `modes/mode6/video_generator.py` — передавать реплики в промпт вместо описания действий

---

### 3. Персонажи трансформируются в людей
**Проблема:** Кукуруза превращается в человека, меняются тела/волосы/руки.

**Причина:** Недостаточно сильные инструкции в промпте + FastGen может игнорировать референсы.

**Решение:**
- Усилить секцию REFERENCE IMAGES:
  - "STRICT: Characters must remain vegetable characters throughout"
  - "NO human transformation allowed"
  - "Body shape, proportions, colors MUST match reference exactly"
  - "Characters are vegetables with human-like expressions, NOT humans with vegetable features"
- Добавить negative prompt: "no human transformation, no realistic human features"
- Возможно: добавить примеры "хорошо/плохо" в промпте

**Файлы для изменения:**
- `modes/mode6/video_generator.py` - секция REFERENCE IMAGES

## Проблемы монтажа видео

### 4. Нет звука видео, только музыка
**Проблема:** Оригинальный звук/озвучка видео от FastGen не слышна, только фоновая музыка.

**Причина:** В `video_assembler.py` видео склеиваются без сохранения аудио дорожки.

**Решение:**
- Сохранять аудио из исходных видео FastGen
- Микшировать: видео-аудио на 100% + музыка на 15-20%
- Использовать `composite` для наложения аудио

**Файлы для изменения:**
- `modes/mode6/video_assembler.py` - функция `assemble_mode6_video()`

---

### 5. Разнообразие локаций
**Проблема:** Все сцены происходят в однотипных локациях (все в парке или все дома).

**Причина:** В промпте статичная локация без привязки к контексту сцены.

**Решение:**
- Добавить в промпт выбор локации на основе эмоции/контекста сцены:
  - Драма/конфликт: улица ночью, тёмная аллея, подъезд
  - Романтика: кафе, закат на набережной, балкон
  - Комедия: яркий супермаркет, парк развлечений, кухня
  - Шок/твист: пустая комната, лифт, крыша здания
- Использовать LLM для подбора локации под контекст сцены
- Локации должны чередоваться: внутри → снаружи → внутри

**Файлы для изменения:**
- `modes/mode6/video_generator.py` - добавить логику выбора локации
- `modes/mode6/scenario_writer.py` - генерация локации для каждой сцены
