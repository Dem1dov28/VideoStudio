# 🚀 БЫСТРЫЙ СТАРТ - Система лимитов

## 1️⃣ Запуск

```bash
# Терминал 1 - Backend
uvicorn server:app --reload --port 8000

# Терминал 2 - Frontend
cd frontend
npm run dev
```

## 2️⃣ Настройка

1. Откройте http://localhost:5173
2. В **левой панели** → "**Лимит генерации**"
3. Выберите лимит: **1, 2 или 3 видео/час**

## 3️⃣ Использование

### Запуск видео
- Просто создавайте видео как обычно
- Если лимит доступен → старт сразу
- Если лимит исчерпан → добавление в очередь

### Очередь
- Видна в левой панели
- Можно удалять (кнопка ❌)
- Автозапуск каждый час в 00 минут

## 4️⃣ Как работает

```
Пример при лимите 2 видео/час:

14:15 - Запущено: 2 видео (лимит исчерпан)
14:30 - Попытка запуска → добавлено в очередь
15:00 - Обновление лимита → очередь запущена (2 видео)
16:00 - Обновление лимита → очередь запущена (осталось 1 видео)
```

## 5️⃣ Тестирование

```bash
# Backend тесты
python test_rate_limit_full.py

# Все тесты должны пройти ✅
```

## 6️⃣ Проверка состояния

**В браузере (Console):**
```javascript
// Посмотреть текущее состояние
const data = JSON.parse(localStorage.getItem('rateLimit'));
console.log(data);
```

**API запрос:**
```bash
curl http://localhost:8000/api/rate-limit/status
```

## ⚠️ Важно

- Лимит обновляется **ровно в 00 минут** (14:00, 15:00...)
- Данные сохраняются после перезагрузки браузера
- Backend проверяет лимит даже если frontend пропустил
- Очередь обрабатывается автоматически

## 🔧 Сброс

Если нужно сбросить всё:

**Browser Console:**
```javascript
localStorage.removeItem('rateLimit');
location.reload();
```

**Backend:** Перезапустить сервер
