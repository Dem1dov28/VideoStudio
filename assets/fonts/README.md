# Fonts

Place **Inter** static TTFs here (recommended) for a consistent Shorts look:

- `Inter-Bold.ttf`
- `Inter-Regular.ttf` (optional; bold is used for most overlays)

Get them from [Google Fonts → Inter](https://fonts.google.com/specimen/Inter) → Download → `static/`.

If these files are absent, the app uses **Segoe UI / Arial** on Windows (still supports Cyrillic).
